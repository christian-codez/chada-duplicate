Engineering notes

Behavior, states & handoff notes

Interaction flows

A

Single duplicate

Hover row → Duplicate → success notice; the copy appears as a draft, link jumps to its editor.

B

Bulk duplicate

Check rows → Bulk Actions: Duplicate → Apply; one summary notice for the batch.

C

From the editor

Copy to a new draft → "Duplicating…" → redirect to the new draft in place.

D

Dismiss cross-sell

Dismiss → panel gone for good, stored per user. Never reappears.

States covered & tradeoffs flagged

Native select, no custom dropdown. Bulk "Duplicate" is a plain <option> — no JS menu, so it inherits WP focus & AA contrast for free.
Status never by color alone. "In stock", Draft and notices always pair an icon or text label with color.
Variations are the slow path. A 6-variation product clones more than a post — confirmation waits for the copy to finish, then notifies.
Responsive down to mobile admin. Row actions collapse with WP's native list-table behavior; nothing custom to maintain.
Delivered: A1–A4, B (block + classic), C, D — all at native wp-admin fidelity.
